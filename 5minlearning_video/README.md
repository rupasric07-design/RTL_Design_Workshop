# RTL Design and Synthesis Workshop

**Presented by:** Rupa Sri
**Domain:** VLSI Design

## Overview

This repository documents my learning experience from the RTL Design and Synthesis Workshop. I learned the fundamentals of digital design, Verilog HDL, RTL coding, simulation, logic synthesis, and gate-level verification.

## Topics Learned

* Register Transfer Level (RTL)
* Verilog HDL and RTL Coding
* RTL Simulation and Testbench Development
* Logic Synthesis and Gate-Level Netlists
* Gate-Level Simulation (GLS)
* Synthesis Optimization
* If-Else and Case Statements
* For Loops and Generate Blocks
* Multiplexer and Demultiplexer
* Ripple Carry Adder

## Tools Used

* Verilog HDL
* Icarus Verilog
* GTKWave
* Yosys

## Learning Outcomes

* Understood the RTL design flow.
* Learned to write and simulate Verilog code.
* Understood the conversion of RTL code into a gate-level netlist.
* Learned about latch inference and synthesis optimization.
* Gained practical knowledge of basic digital circuits.
